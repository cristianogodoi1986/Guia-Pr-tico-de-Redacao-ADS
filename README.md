## 🎯 Sobre o Projeto

O **Guia Prático de Redação: Dissertação Expositiva × Dissertação Argumentativa** é um material educacional desenvolvido em **HTML5**, com uma interface moderna, responsiva e organizada para facilitar o aprendizado.

O projeto foi criado com o objetivo de tornar mais simples a compreensão de uma dúvida bastante comum entre estudantes:

> **Como saber se um texto é expositivo ou argumentativo?**

A proposta utiliza explicações objetivas, exemplos práticos, tabelas comparativas, fluxogramas e atividades para transformar um conteúdo tradicionalmente teórico em uma experiência de aprendizagem mais visual e interativa.

O tema utilizado como base para os exemplos é:

> **"Impactos das redes sociais na educação"**

A partir dele, o projeto demonstra na prática as diferenças entre:

| Dissertação Expositiva        | Dissertação Argumentativa |
| ----------------------------- | ------------------------- |
| 📖 Explicar                   | 🎯 Defender               |
| 💡 Informar                   | 🗣️ Convencer             |
| ⚖️ Objetividade               | 📌 Posicionamento         |
| 🔎 Apresentar informações     | 🧠 Defender uma tese      |
| 🚫 Evita julgamentos pessoais | ✅ Utiliza argumentos      |

## 🚀 Objetivos

### Objetivo principal

Criar um material digital capaz de auxiliar estudantes na identificação e produção de dissertações expositivas e argumentativas.

### Objetivos específicos

* 📖 Explicar as características de cada tipo textual.
* 🔎 Facilitar a identificação das diferenças entre exposição e argumentação.
* 🧠 Apresentar exemplos práticos e comentados.
* 📊 Criar uma comparação visual entre os dois modelos.
* 🧭 Desenvolver um fluxograma para identificação rápida.
* ⚠️ Demonstrar erros comuns na produção textual.
* ✍️ Estimular a prática por meio de exercícios.
* 💻 Aplicar conceitos de desenvolvimento web em um projeto educacional.

## 🧠 Conceito Central

Uma das ideias principais utilizadas no material é a associação entre a **finalidade comunicativa** e o verbo-chave de cada modalidade.

### 📖 Dissertação Expositiva

> **EXPLICAR / INFORMAR**

Seu objetivo principal é apresentar informações, conceitos, fatos ou fenômenos de maneira clara, objetiva e organizada.

### 🎯 Dissertação Argumentativa

> **DEFENDER / CONVENCER**

Seu objetivo é apresentar uma posição sobre determinado tema e utilizar argumentos para sustentá-la.

Essa distinção funciona como uma espécie de "atalho mental" para identificar rapidamente o tipo de texto.

# 📖 Estrutura do Material

O guia foi organizado em **10 seções principais**:

### 01 — 🏛️ Capa Acadêmica

Apresentação visual do material e introdução ao tema.

### 02 — 📌 Contextualização

Explicação sobre a importância de diferenciar os dois tipos de dissertação.

### 03 — 📖 Dissertação Expositiva

Conceitos, características, finalidade, estrutura e regras de produção.

### 04 — 📝 Exemplo Expositivo

Texto prático sobre os impactos das redes sociais na educação, acompanhado de explicações.

### 05 — 🎯 Dissertação Argumentativa

Apresentação do conceito de tese, argumentos e organização textual.

### 06 — 📝 Exemplo Argumentativo

Análise detalhada de um texto argumentativo.

### 07 — 📊 Comparação Direta

Tabela comparativa entre os dois tipos textuais.

### 08 — 🧭 Fluxograma de Identificação

Sistema de perguntas para ajudar o estudante a identificar o tipo textual.

### 09 — ⚠️ Erros Comuns

Apresentação de erros frequentes e suas respectivas correções.

### 10 — 🏆 Desafio Final

Atividades de classificação, produção textual e checklist de autoverificação.

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

## 2️⃣ Entrar na pasta

```bash
cd SEU-REPOSITORIO
```

## 3️⃣ Abrir o projeto

Localize o arquivo:

```text

```

* Microsoft Edge
* Mozilla Firefox
* Safari

# 🌐 Publicação com GitHub Pages

O projeto também pode ser disponibilizado gratuitamente utilizando o **GitHub Pages**.

### Passos:

1. Acesse o repositório no GitHub.
2. Abra **Settings**.
3. Entre em **Pages**.
4. Em **Build and deployment**, selecione:

   * Branch: `main`
   * Folder: `/root`
5. Clique em **Save**.

Após a publicação, o GitHub disponibilizará uma URL pública para acesso ao projeto.
